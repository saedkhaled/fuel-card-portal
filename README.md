# Fleet Cards Demo

Flutter foundation for an Android-first fuel-card customer portal. This step implements offline sign-in, the guarded five-tab shell, and Arabic and English.

```sh
flutter pub get
flutter run -d <android-device-id>
```

Sign in with demo number `0900000000` and code `246810`. The app starts in Arabic. Use the language button to switch to English. [Foundation handoff](.spec/fuel-card-portal/step1_foundation/package.md)
