Observed 25 November 2026 through normal UI interaction on the Pixel 9 Pro AVD running Android 16 (API 36). Installed and launched `Stage_2026_11_17.apk`, package `sy.goldengate.gg_portal`, version 1.0.2 (8), declared minSdk 24 / targetSdk 36. SHA-256 `9e49e4d15367aa65aa73f4ae02d2845a9475c02e86c11684743adafcab55b47f`. Used ADB taps and UI hierarchy on a single supplied account. Arabic sign-in and the English switch were observed. ## Evidence limits

This is a UI sample of one APK build, account, and device. Note submissions, download/export payloads, OS share and directions results, notification permission and delivery, top-up interaction results, backend rules, account variants, and error responses beyond sampled sign-in validation remain unverified. UI affordances above are observed, and proposed implementations are listed separately as demo behavior. The plan uses local substitutes for external services. Existing reference UI copy, assets and real account records stay out of the deliverables.
