# Fuel-card portal agent instructions

This repository contains the planning baseline for an Android-first Flutter demo. A request to plan or inspect the reference authorizes planning or inspection. Implement when requested.

- Open [spec memory](.spec/fuel-card-portal/memory.md) and the selected package first. Load the proposal, architecture or evidence sections that package references. Use [command index](.spec/fuel-card-portal/prompt.md) for package execution and handoff.
- Repo-local skills are under [.agents/skills](.agents/skills). Read `portal-spec` for package work, `portal-flutter` for implementation, and `portal-android-qa` for device verification. Direct file reads work when the host does not discover repo-local skills.
- Keep staging credentials, APK, screenshots with live data, and brand assets outside the repo. Use the planned fictitious account and a distinct visual identity for product work.
- Own touched paths, record the Git baseline, and preserve changes from other sessions. Document evidence with commands and outcomes. Only mark a task complete after its verification passes or a specifically accepted gap is recorded.
